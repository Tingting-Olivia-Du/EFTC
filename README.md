# EFTC: English Finance Textbooks Corpus — Lexical Coverage Study

Data and code for *"Are Chinese finance undergraduates ready for
English-medium instruction? Evidence from lexical coverage analysis of
English finance textbooks."*

The study asks whether the vocabulary Chinese finance undergraduates are
expected to know by the time they enter (and progress through) English-medium
instruction (EMI) programmes — the High School Word List, CET-4, CET-6, and
three widely-used academic word lists (AWL, NAWL, AVL) — is actually enough to
read their English-language finance textbooks. It answers this with a
corpus-based lexical coverage analysis: a self-built **English Finance
Textbooks Corpus (EFTC)** of 94 textbooks across 19 finance courses
(~16.35 million running words), checked against each word list at six
morphological "affix levels" (Bauer & Nation, 1993), with and without a
BNC/COCA supplementary list (proper names, marginal words, transparent
compounds, acronyms).

**Headline finding:** none of the three general word lists (HSWL, CET-4,
CET-6) or three academic word lists (AWL, NAWL, AVL) — alone or combined —
reach the 95% token-coverage threshold generally accepted as necessary for
adequate reading comprehension. The best-performing combination (AVL +
general word lists + BNC/COCA supplement) tops out at 94.09%.

## Repository layout

```
paper/           the manuscript (paper.md) and the associated tracked-changes docx
analysis/        clean, dependency-free Python implementation of the paper's
                 coverage/overlap metrics, used to independently verify every
                 numeric table in the paper
data/            the raw inputs analysis/ runs against: the EFTC corpus
                 frequency file, the six core word lists, and cached
                 intermediate pipeline outputs (see report, Finding R1)
report/          verification_report.md — the full write-up of the
                 independent data/content check (what matches, what doesn't,
                 and why)
output/          CSV results generated by running analysis/ (git-tracked so
                 the findings are visible without re-running anything)
archive/         the original exploratory research pipeline (corpus
                 construction, PDF extraction, word-list generation scripts,
                 every intermediate result file from Oct 2024-Jan 2025).
                 Kept for provenance; see archive/README.md. Raw extracted
                 textbook prose is excluded from version control (copyright).
```

`paper/`, `analysis/`, `data/`, `report/`, and `output/` are the current,
citable state of the project. `archive/` is historical/exploratory and is not
required to understand or reproduce the paper's results.

## Quick start: reproducing the coverage numbers

No dependencies beyond Python 3 (standard library only). Run everything from
the repository root:

```bash
# 1. Independently recompute every table cell that raw data supports
#    (corpus totals, Table 4 overlaps, Table 6/7/8 Level-1 rows, Table 10
#    standalone AWL/NAWL/AVL rows) directly from data/wordlists/ + the corpus.
python3 analysis/run_level1_reproduction.py

# 2. Cross-check the remaining table cells (which depend on word-family-
#    expanded Level 2-6 lists and BNC/COCA supplementary lists no longer
#    in the repo, see report) against the pipeline's own cached output.
python3 analysis/verify_cached_tables.py
```

Each script prints a pass/fail summary and writes a detailed CSV to `output/`.
`analysis/coverage_lib.py` is the reusable core: `Corpus`, `coverage_stats()`
(attestation rate / type coverage / token coverage), and `overlap_stats()`
(pairwise word-list overlap), implemented directly from the metric
definitions in the paper's Section 4.2.2 — not copied from the archived
pipeline scripts, so it functions as an independent check.

## What's verified vs. what depends on the archive

- **Independently reproducible from `data/` alone:** corpus totals, Table 4
  (all pairwise overlaps), the Level-1 rows of Tables 6/7/8, and the
  standalone-list rows of Table 10. All match the paper exactly.
- **Only checkable against cached output, not fully re-derivable:** Table 3,
  the Level 2-6 rows of Tables 6/7/8, Table 5, Table 9, and the starred rows
  of Table 10. These need the word-family-expanded word lists and BNC/COCA
  supplementary lists that the original pipeline built but that no longer
  exist in this repository (only their output does) — see the report's
  "Reproducibility gap" finding for what that means and what it would take to
  close it.

Full details, severity ratings, and exact line numbers for every finding
(including a Discussion-section numerical error and six missing reference
entries) are in [`report/verification_report.md`](report/verification_report.md).

## Data notes

- `data/wordlists/eftc_corpus.json` is a word→frequency dictionary (no
  sentences or continuous prose) — safe to distribute.
- `archive/` excludes the raw, near-verbatim textbook text that the original
  PDF-extraction pipeline produced (git-ignored; see `.gitignore`). Everything
  that remains there is either code, word lists, or word-frequency data.
